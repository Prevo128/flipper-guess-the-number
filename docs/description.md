# Guess The Number

A classic number guessing game with two modes and plenty of animations.

## Game modes
- **Be the guesser:** the Flipper picks a secret number and tells you if your guess is too big or too small
- **Let the computer guess:** think of a number and the Flipper finds it with binary search. It even tells you how many tries it needs at most. Lie to it and it will notice!

## Features
- Custom ranges from -999 to 9999 (default 1 to 100)
- **Hall of Fame** with your top 3 scores, plus stats for both modes, saved on the SD card
- Scores reward few tries on big ranges: 100 points means you played like a perfect binary search
- Animated intro, number reels, confetti, LED and vibration feedback

## Controls
- **Your turn:** Up/Down change the number by 1, Left/Right by 10 (hold to go fast), OK to guess
- **Computer's turn:** Left = lower, Right = higher, OK = correct
- **Stats:** Left/Right switch pages, hold OK to reset
- Hold Back anywhere to quit
